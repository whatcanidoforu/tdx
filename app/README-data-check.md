# 通达信数据体检（data-check）

检查本地 **5 分钟线**和**日线**的起始/结束日期，确认数据覆盖范围、发现停更和缺口。

## 快速开始

双击 **`数据体检.bat`**，或：

```bat
node data-check.mjs
```

## 常用命令

```bat
node data-check.mjs                       # 全部（5分钟 + 日线）
node data-check.mjs --period=5min         # 只查 5 分钟线
node data-check.mjs --period=day          # 只查日线
node data-check.mjs --market=sh           # 只查沪市
node data-check.mjs --code=sh600000       # 只查单只
node data-check.mjs --export              # 导出明细 CSV
```

`--code` 输出更直观：

```
── 5分钟 ──
  sh600000
    5分钟：2026-07-16 ~ 2026-11-11，共 3792 条

── 日线 ──
  sh600000
    日线：1999-11-10 ~ 2026-11-11，共 6425 条
```

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--period=5min\|day` | 两个都查 | 周期 |
| `--market=sh,sz,bj` | 全部 | 市场 |
| `--code=sh600000` | — | 只查单只 |
| `--tdx=<目录>` | `D:\MyTools\new_tdx` | 通达信目录 |
| `--export` | 否 | 导出每个文件的起止日期到 CSV |
| `--out=<目录>` | `./data-check` | 导出目录 |
| `--top=10` | 10 | 每个分布表显示前 N 类 |
| `--limit=100` | — | 每市场只查前 N 个（调试） |

## 性能

**只读每个文件的首尾 32 字节**，不加载全文，所以很快：

| 周期 | 文件数 | 耗时 |
|---|---|---|
| 5 分钟（三市全量） | 52,884 | ~10 秒 |
| 日线（三市全量） | 22,803 | ~8 秒 |

## 能看出什么

| 现象 | 含义 |
|---|---|
| **起始日大量集中在某一天** | 通达信只保留最近 N 天，或那天做过全量下载 |
| **结束日不统一** | 部分标的停更（停牌、退市、或没下载到最新） |
| **记录数为 1~2** | 新上市或长期停牌 |
| **异常文件数 > 0** | 文件损坏或格式不符 |

### 实测发现的典型情况

**5 分钟线起始日分三批**：
- `2026-11-06`（22114 个，79.5%）—— 只有 1 天数据，新下载的标的
- `2026-07-16`（4739 个，17.0%）—— 完整保留 76 个交易日
- `2026-10-23` 及其他 —— 零星新增

这说明通达信的 5 分钟数据**不保证全量保留**，不同标的覆盖范围差异很大。回测时要注意样本量。

**日线起始日跨度极大**（1990~2011），因为老股票保留全部历史，新股从上市日开始。

# 通达信 · 盘中跌幅扫描

每到 15 分钟节点，自动扫描 **当日跌幅超过 5%** 的股票，输出排行榜并落地 CSV。

## 快速开始

| 文件 | 作用 |
|---|---|
| `启动扫描.bat` | **双击即用**：常驻，按检查点自动扫描 |
| `扫描一次.bat` | 双击立即扫一次，看完就关 |

结果写在 `tdx-loss-scan\` 目录：

- `latest.csv` —— 每次扫描覆盖，适合用 Excel 挂着看
- `YYYYMMDD-HHmmss.csv` —— 每次扫描留档，可复盘
- 控制台同时打印排行榜表格

## 数据怎么来的

两条通道，优先用本地日线（快且免登录）：

**主通道 · 本地日线**

通达信运行时会实时把当日行情写进 `vipdoc\{sh,sz,bj}\lday\*.day`。
脚本直接读每个文件最后两条 K 线：

- 倒数第二条收盘价 = **昨收**
- 最后一条收盘价 = **当前价 / 当日收盘价**

当日跌幅 = `(当前价 - 昨收) / 昨收`。全市场 5500 多只扫一遍约 **0.7 秒**。

**备用通道 · 行情主站**

直连通达信行情服务器（TCP 7709），自行实现证券列表协议，拿到全市场「代码 / 名称 / 昨收」。
主要用于**补股票名称**和交叉校验，结果按天缓存到 `tdx-loss-scan\names.json`，不会每次联网。

## 排除了什么

| 排除项 | 原因 |
|---|---|
| 退市股 | `vipdoc` 里留着历史文件，最后交易日可能是几年前的，直接算会得出 -62% 这种假跌幅。脚本按「最后一条 K 线 = 当前交易日」过滤，自动剔除 |
| 停牌股 | 当日无成交（成交量为 0） |
| ST / \*ST / 退 | 默认排除，加 `--include-st` 可纳入 |
| 指数、基金、债券、可转债 | 只保留沪深主板、创业板、科创板、北交所 A 股 |

## 检查点

```
09:30
09:45  10:00  10:15  10:30  10:45
11:00  11:15  11:30
13:15  13:30  13:45
14:00  14:15  14:30  14:45
15:00
```

开盘 09:30、收盘 15:00 都在内；午休 11:30–13:15 自动跳过。
到点后**再等 3 秒**才扫，避开整点行情跳动的瞬间（可用 `--delay=<秒>` 调）。

## 命令行参数

```bat
node loss-scanner.mjs --tick                 常驻自动扫描
node loss-scanner.mjs --once                 立即扫描一次

--threshold=5      跌幅阈值，默认 5（即超过 5%）
--tdx=<目录>       通达信安装目录，默认 D:\MyTools\new_tdx
--times=09:30,10:00,11:30,13:15,15:00        自定义检查点
--delay=3          到点后延迟几秒再扫
--include-bj       把北交所算进来
--include-st       把 ST 股算进来
--out=<目录>       输出目录，默认 ./tdx-loss-scan
--quiet            只写文件，不打印表格
```

## 设置成开机自启（可选）

1. `Win + R` 输入 `shell:startup` 打开启动文件夹
2. 右键 `启动扫描.bat` → 创建快捷方式，把快捷方式拖进去

## 注意

- 通达信需要**保持运行**，否则本地 `vipdoc` 不会刷新到当日，扫出来的会是上一个交易日
- 主通道纯本地读取，不需要联网；只有补名称时才连行情主站，且按天缓存
- 文件结构：

| 文件 | 作用 |
|---|---|
| `loss-scanner.mjs` | 主程序：参数解析、输出、调度 |
| `market-scan.js` | 本地日线扫描、退市股过滤 |
| `market-data.js` | 行情主站证券列表、股票池 |
| `name-service.js` | 名称表获取与缓存 |
| `tdx-protocol.js` | 通达信 TCP 协议（7709）实现 |
| `time-format.js` | 时间格式化 |
| `test-schedule.mjs` | 调度逻辑自测 |

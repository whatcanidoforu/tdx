# tdx-model：用通达信指标预测「次日收盘价 / 次日最高价」

这个目录是 `tdx-model` 分支新增的模型部分：把 `dsh-tdx` 前端已经实现的
**HJ 指标 + MACD + 日线 OHLCV** 作为特征，训练 LightGBM 模型，
预测每只 A 股**下一个交易日的收盘价和最高价**。

> 分支：`tdx-model`（从 `web` 仓库 `main` 切出）
> 代码位置：`web/model/`
> 数据：`D:\MyTools\new_tdx_day`（本地通达信日线，12,218 个文件）

---

## 1. 结论速览

回测区间：**2025-01-01 ~ 2026-10-21**（413 个交易日，测试集完全不参与训练）

| 任务 | IC 均值 | ICIR | 正 IC 占比 | R² | 方向命中率 |
|---|---|---|---|---|---|
| 预测**次日收盘收益** | **0.0742** | 0.61 | 74.3% | 0.011 | 54.2% |
| 预测**次日最高收益** | **0.2889** | 1.93 | 96.9% | 0.116 | 87.6% |

- 次日收盘：预测最高的 50 只股票，次日平均收益 **+2.08%**（全市场均值 +0.02%）
- 次日最高：预测最高的 50 只，次日平均最高涨幅 **+6.80%**（全市场 +2.09%）
- 分年度：收盘 IC 2025=0.087 / 2026=0.058；最高 IC 2025=0.286 / 2026=0.293

**但要看清这个结果的性质：**

1. 模型 Top50 里 **91.9% 是「当日涨停」的股票**——模型主要学的是 A 股著名的
   **「涨停次日溢价 / 连板延续」**效应。简单规则（按当日涨幅选 Top50）次日只有 +0.96%，
   模型挑出 +2.08%，说明模型在涨停股内部做了进一步筛选，但本质上仍是涨停博弈。
2. 剔除当日涨停样本后，模型对普通股票的 IC 仍有 **0.0709**，说明 HJ/MACD/量价特征
   对次日收益有独立于涨停的信号。
3. 「次日最高收益」的 IC 高达 0.29，**主要来自波动率可预测性**（高波动股票次日最高价
   天然更高），不能把它当成方向判断；方向信号看「次日收盘收益」的 IC 0.074。

## 3. 特征（57 个）

全部只用「当天及以前」的数据，不使用未来信息。

| 类别 | 特征 |
|---|---|
| HJ 指标（对齐 `web/src/formulas/hj.js`） | `hj10`、`hj11`、`hj10-hj11`、`hj5`（买入信号）、`hj_accel`（加速值）、`hj_accel_chg`、加速方向 |
| MACD(12,26,9) | `macd_dif`、`macd_dea`、`macd_hist`、`dif-dea`、`hist`/`dif` 变化、金叉、`dif>dea` |
| 均线 | `close_ma5/10/20/60`（相对收盘）、`ma5/ma20`、`ma20` 斜率 |
| 动量 | 1/3/5/10/20/60 日收益 |
| 震荡指标 | `rsi14`、`kdj` K/D/J、`boll` 位置/宽度、`atr14` |
| 价格行为 | 振幅、实体、上下影线、跳空、收盘位置、20/60 日区间位置、距 20 日高低点 |
| 量能 | 量比 5/20、额比 5、对数成交额、20/60 日波动率 |
| 日历 | 月份 sin/cos、星期 |
| 市场环境 | 上证指数 1/5/20 日收益、指数 20 日波动、全市场上涨家数占比、截面收益均值/标准差 |

> 特征重要性上，**次日收盘**主要靠 `ret1`、`amplitude`、`vol_ratio20`、`gap`、`atr14_pct`、
> 成交额等；**次日最高**主要靠 `ret1`、`atr14_pct`、`amplitude`、`vol20`、`dist_low20`。
> 市场环境特征（指数/宽度）在 gain 里排名高，但它们对“同一天所有股票”取值相同，
> 只影响时间维度的拟合，不参与横截面排序。

## 4. 标签

对每只股票、每个交易日 t：

```text
y_close_ret = close[t+1] / close[t] - 1      # 次日收盘收益
y_high_ret  = high[t+1]  / close[t] - 1      # 次日最高收益（次日最高价相对今日收盘）
```

预测时换算成价格：

```text
pred_close_px = close[t] * (1 + pred_close_ret)
pred_high_px  = close[t] * (1 + pred_high_ret)
```

## 5. 模型与训练

- 模型：**LightGBM 回归**（两个目标各一个模型）
- 参数：`num_leaves=63`、`learning_rate=0.05`、`min_data_in_leaf=500`、
  `feature_fraction=0.8`、`bagging_fraction=0.8`、`lambda_l2=1`、500 轮 + 50 轮早停
- 训练耗时：**2.7 分钟**（16 线程），最佳轮数：收盘 158 轮 / 最高 364 轮
- 时间切分：训练 `<2023-01-01`，验证 `2023~2024`，测试 `>=2025-01-01`
- 评估：按天计算横截面 Spearman IC、十分位多空、Top50 组合、方向命中率

### 泄漏自检

把标签整体后移一天（用 t 日特征预测 t+2），模型在验证集第 **3 棵树**就早停，
IC ≈ 0；而预测 t+1 的 IC 为 0.074。说明特征里没有混入未来信息，
t+1 的信号是真实的（至少在测试期内）。

## 8. 局限与风险（务必阅读）

1. **幸存者偏差**：TDX 本地数据只有当前仍在列表的股票，退市股缺失，回测收益会被高估。
2. **交易不可行性**：模型 Top50 主要是当日涨停股，实际盘中往往买不进；且未考虑
   手续费、滑点、冲击成本、涨跌停无法成交。
3. **次日最高价不可直接交易**：预测的「最高价」只是一个波动幅度估计，实盘无法保证卖在最高点。
4. **测试期仅 1.8 年、单一行情**：IC 会随市场风格变化，不能保证未来稳定。
5. 这不是投资建议，只是「指标 → 次日价格」的机器学习建模练习，实盘使用前必须做
   更严格的滚动回测和风控。

### 10.4 这一版的真实结论

1. **数据翻倍确实有提升**：次日最高 IC 从 0.244 → 0.272，Top5 平均最高涨幅从 2.91% → 3.19%；
   GRU 的次日收盘日级 IC 从 0.025 → 0.083。
2. **但次日收盘方向仍然不可预测**：横截面 IC 只有 0.021，最佳轮数 3 轮。
3. **次日最高价（波动幅度）依旧是最稳的目标**：IC 0.272，且 5/15/30 分钟特征比纯日线有
   +0.013 的增量——方向是对的，但幅度还小。
4. **单股票 600281 仍然不可用**：448 天、2.1 万根 bar 听着多，但独立交易日只有 448 个，
   序列模型从第 1 轮就开始过拟合，测试 IC 为负。
5. **GRU 依然过拟合**：44.5 万个训练窗口彼此高度重叠（相邻窗口共享 47 根 bar），
   真正独立的信息只有 445 天。LightGBM 用日级样本反而更稳。
6. 想真正发挥多周期模型，仍然需要：
   - **3~5 年**的 5 分钟历史（现在 448 天还是短）；
   - 或把股票池从 26 只扩到全市场 5,000+ 只（448 天 × 5,000 只 ≈ 200 万个日级样本）。

## 11. 买入信号 + 3 日最高点预测（daily 条件策略）

这是第 6 版：不做全市场回归，而是先定义「买点」，再预测买点之后 3 天内的最高点。

### 11.1 信号定义（T 日收盘买入）

```text
条件 1：HJ10 上穿 HJ11 —— 昨日 hj10 <= hj11，今日 hj10 > hj11
条件 2：MACD DIFF 增大 —— dif[t] > dif[t-1]（dif 为 12/26 原始 DIFF）
条件 3：T 日 开盘/收盘/最高/最低/振幅/涨跌幅 作为模型特征
目标：  fwd_high_ret = max(high[T+1], high[T+2], high[T+3]) / close[T] - 1
```

> 条件 1+2 是硬性买入过滤；条件 3 的 OHLC/振幅/涨跌幅作为预测特征参与模型。
> 如果你希望把「振幅 > x%」「收盘 > 开盘」等也做成硬过滤，脚本里加一行即可。

### 11.2 数据与信号规模

| 项目 | 数值 |
|---|---|
| 数据源 | `D:\MyTools\new_tdx\vipdoc\{sh,sz,bj}\lday`（全部 A 股日线） |
| 股票数 | 5,747 只（5,916 个文件） |
| 全样本 | 18,253,446 个「股票-交易日」 |
| 日线范围 | 1991-04 ~ 2026-10-28 |
| **满足条件的信号** | **1,159,114 条**（约占全部交易日的 6.3%） |
| 测试集信号 | 69,041 条（2026-01 以后） |

### 11.3 信号本身的历史表现（不训练模型，直接统计）

| 指标 | 信号日 | 全市场基准 |
|---|---|---|
| 3 日最高涨幅均值 | **+4.22%** | +3.95% |
| 中位数 | +2.75% | — |
| 3 日内最高涨幅 ≥ 2% | 59.9% | 58.2% |
| ≥ 3% | 47.0% | 44.9% |
| ≥ 5% | **29.2%** | 27.0% |
| ≥ 10% | 9.9% | 8.7% |
| 3 日内最大回撤（最低点）均值 | -3.40% | — |

最高点出现时间：**T+1 日 44.4%**、T+2 日 22.6%、T+3 日 33.0%。

> 实话：这个信号本身只有**温和优势**（均值 +0.27 个百分点，5% 命中率 +2.2 个百分点）。
> 它的价值不在「买入后一定涨」，而在「买点之后 3 天内大概率会有冲高机会」。

### 11.4 预测模型（LightGBM）

训练：1,006,885 条（<2025）| 验证：83,188 条（2025）| 测试：69,041 条（2026 以后）

| 任务 | 指标 |
|---|---|
| 回归：预测 3 日最高涨幅 | **IC = 0.342**，R² = 0.139，MAE = 3.35% |
| 分类：3 日内涨幅 ≥ 5% | **AUC = 0.715**，AP = 0.511（正样本率 29.8%） |

按预测值分 5 组，实际 3 日最高涨幅：**2.16% / 3.14% / 4.05% / 5.02% / 7.65%**（单调递增）。

Top 特征：`ret1`（当日涨跌幅）、`atr14_pct`、`vol20`、`amplitude`、`upper_shadow`、`vol_ratio5`、

### 13.2 振幅对后续最高点的影响（K=3）

| 振幅区间 | 信号数 | 3 日最高均值 | 冲高≥5% 比例 |

| 7–10% | 103,433 | 5.63% | 42.4% |

### 13.4 极端振幅是不是脏数据？

- A 股涨跌停限制：主板 ±10%，创业板/科创板 ±20%，北交所 ±30%；因此**振幅可以达到约 40%**（20cm 板从跌停到涨停），属于正常行情。
- 5~7%：正常偏大；10~15%：大；15~20%：很大但真实；20~40%：20cm 板剧烈波动，真实但风险高。
- **真正的脏数据是数学上不可能的记录**，例如：
  - `600629` 2007-10-26：振幅 **587.6%**、涨跌幅 **1097.5%**
  - `000592` 2008-04-14：振幅 **405.9%**、涨跌幅 **1164.7%**
- 这些集中在 1990 年代~2000 年代初的老数据。当前处理：
  - 过滤 `|T日涨跌幅| > 35%` 或 `振幅 > 50%`（K=3 数据 830,682 行中只去掉 **56 行**）；
  - 5~7% 不删，15%+ 保留作为特征/风险标记；
  - 后续可以再加「板块类型（10cm/20cm/30cm）」特征，让模型区分不同涨跌停制度。

### 13.5 「大模型能处理这类不清楚的问题吗」

能，但要分清两件事：

- **模型能学**：把振幅、涨跌幅、量比、量价配合等作为特征，MLP/树模型可以自动学习它们与未来冲高的非线性关系，不需要你写死规则；
- **模型不能凭空创造信息**：振幅与未来最高点的关系本质是「波动率聚集」，这是统计规律，不是因果；而且对收盘方向几乎没有帮助。

实测：加振幅/量能特征后，16 个目标平均 MAE 3.51% → **3.29%**（改善约 6%），
其中 T+1 最高价改善最大（2.55% → 1.90%）。

### 13.6 上影线/下影线「长短」有没有影响？

**先定义「长短」**（两种都算，互相可以换算）：

```text
上影占比 = 上影线 / 当日振幅      （= (high-max(open,close)) / (high-low)）
下影占比 = 下影线 / 当日振幅
上影比例 = 上影 / (上影+下影)      （0.5 = 一样长；>0.5 上影主导）
实体占比 = |收盘-开盘| / 当日振幅  （上影+下影+实体 = 振幅）
```

信号日（K=3，826,080 条）的分布：

| 分位 | 上影占振幅 | 下影占振幅 | 上影/(上+下) |
|---|---|---|---|
| P50 | 21.1% | 15.8% | 57.1% |
| P75 | 37.9% | 30.5% | 82.4% |
| P90 | 55.0% | 47.9% | 100% |
| P95 | 64.8% | 58.9% | 100% |

**「长短」的实用界限**（按占振幅）：

| 上/下影占振幅 | 判定 |
|---|---|
| ≤10% | 短影线（接近光头光脚） |
| 10~30% | 正常 |
| 30~50% | 偏长 |
| >50% | 很长 |
| >70% | 极长 |

上下影比例：**<0.35 下影主导**，0.35~0.65 均衡，**>0.65 上影主导**。

**按上影占比分桶（3 日最高涨幅）：**

| 上影/振幅 | 信号数 | 3 日最高均值 | 冲高≥5% 比例 |
|---|---|---|---|
| 0–5% | 152,424 | **5.22%** | **36.9%** |
| 5–10% | 80,855 | 3.77% | 25.6% |
| 10–20% | 159,307 | 3.81% | 26.1% |
| 20–30% | 139,507 | 3.87% | 26.6% |
| 30–50% | 175,987 | 3.85% | 26.5% |
| 50–70% | 91,199 | 3.82% | 25.9% |
| 70–100% | 26,801 | 4.03% | 27.2% |

2. **双短影（光头光脚/小影线）最好**：3 日最高均值 5.34%、冲高≥5% 38.0%；
   **双长影最差**：3.64%、24.8%。
3. **长上影偏负面**，尤其**涨停后带长上影**：3 日收盘均值 -0.10%，明显弱于非长上影的 +1.61%，是典型的「冲高回落」。
4. 长下影单独看不是稳定利好（U 型：下影 70~100% 反而回升），不能简单理解为「下影长=支撑强」。
5. 模型里原本已有 `upper_shadow`/`lower_shadow`；这次又加了归一化的
   `upper_share`/`lower_share`/`shadow_ratio`/`body_share` 四个特征（66 → 70 维），
   16 目标平均 MAE 仅从 3.295% 微降到 **3.288%** —— 说明影线更适合做**解释/过滤规则**，
   而不是指望它大幅提升预测精度。

> 一句话：**影线短、实体饱满 → 后续冲高概率略高；涨停后长上影要小心「冲高回落」。**

相关系数：

   平开只有 3.63% / 24.1%。
2. **高开后能否守住缺口很关键**：未回补 5.81% vs 回补 4.87%，3 日收盘 +1.03% vs +0.21%。

> 实战含义：**优先"高开且守住缺口 + T 日涨幅 2% 以上"的信号；微涨 0~2% 的最鸡肋；涨停最强但买不进。**

### 13.8 T 日收盘 > MA5 / MA10 / MA20 有影响吗？

**有，而且 MA20 这条最关键；"站上几条"比"是否站上 MA5"更重要。**

**1）单独看三条均线：**

| 条件 | 信号数 | 3日最高均值 | 3日收盘均值 | 冲高≥5% |
|---|---|---|---|---|
| 收盘 > MA5（站上） | 803,971 | 4.16% | +0.34% | 28.6% |
| 收盘 ≤ MA5（跌破） | 25,464 | 3.67% | +0.16% | 24.8% |
| 收盘 > MA10（站上） | 640,063 | 4.26% | +0.32% | 29.4% |
| 收盘 ≤ MA10（跌破） | 189,372 | 3.76% | +0.37% | 25.2% |
| **收盘 > MA20（站上）** | 422,307 | **4.63%** | **+0.50%** | **32.4%** |
| 收盘 ≤ MA20（跌破） | 407,128 | 3.64% | +0.16% | 24.4% |

- 站上 MA5/MA10 只提升 0.4~0.5 个百分点，且 **97% 的信号本来就站上 MA5**，区分度低；
- **站上 MA20 提升约 1.0 个百分点（4.63% vs 3.64%），是最有区分度的一条**。

**2）同时站上几条均线：**

| 站上 MA5/10/20 的条数 | 信号数 | 3日最高均值 | 3日收盘均值 | 冲高≥5% |
|---|---|---|---|---|
| 0 条 | 23,396 | 3.72% | +0.23% | 25.3% |
| 1 条 | 164,897 | 3.76% | +0.38% | 25.1% |
| 2 条 | 221,982 | **3.55%** | **-0.01%** | **23.8%** |
| **3 条全站上** | 419,160 | **4.63%** | **+0.50%** | **32.4%** |

注意：**不是单调关系**——"站上 2 条"反而最弱（通常是站上 MA5/MA10 但跌破 MA20 的反弹形态）。

**3）关键组合（MA5/10/20 三种状态）：**

| 组合 | 信号数 | 3日最高均值 | 3日收盘均值 | 冲高≥5% |
|---|---|---|---|---|
| **站上 5/10/20（全部）** | 419,160 | **4.63%** | +0.50% | **32.4%** |
| 站上 5、10，跌破 20 | 218,900 | **3.54%** | -0.02% | **23.8%** |
| 站上 5，跌破 10、20 | 163,058 | 3.76% | +0.39% | 25.2% |
| 全跌破 | 23,396 | 3.72% | +0.23% | 25.3% |

**"站上 MA5/MA10 但没站上 MA20" 是最差的一档**（3.54%/23.8%），典型的下跌中继反弹。

**4）比"是否站上"更重要的是"站上多少"（偏离幅度）：**

| 收盘相对 MA5 | 信号数 | 3日最高均值 | 冲高≥5% |
|---|---|---|---|
| -10~-5% | 177 | 5.72% | 40.7% |
| -2~0% | 23,746 | 3.54% | 23.8% |
| **0~2%（刚站上）** | 322,436 | **3.01%** | **18.5%** |
| 2~5% | 347,938 | 4.18% | 29.6% |
| 5~10% | 118,114 | 6.43% | 48.0% |
| >10% | 15,483 | 10.04% | 66.3% |

- **刚刚站上 MA5（0~2%）是最弱的**（3.01%/18.5%），比跌破均线还弱；
- 站上 5~10% 或 >10% 则明显更强——"强势远离均线"比"贴均线"好。
- MA10/MA20 也类似：贴合均线（0~2%）弱，远离（>5%）强；深跌破（≤-10%）反而波动大、冲高概率高。
- 相关系数：`close_ma5` +0.261、`close_ma10` +0.172、`close_ma20` +0.100（与 3 日最高涨幅）。

**5）"均线多头排列"（MA5>MA10>MA20）反而没有优势：**

| 状态 | 信号数 | 3日最高均值 | 冲高≥5% |
|---|---|---|---|
| MA5>MA10>MA20（多头排列） | 478,881 | 3.82% | 25.7% |
| 非多头排列 | 350,554 | **4.58%** | **32.2%** |

原因：非多头排列里包含大量"深跌/超跌反弹"信号，波动大、冲高幅度大；多头排列更"稳"但弹性小。
**如果你的目标是"最高点涨幅"，不必强求多头排列；如果追求稳健，则优先全站上。**

**结论：**

1. **三条里 MA20 最重要**：站上 MA20 把 3 日最高均值从 3.64% 提到 4.63%。
2. **三条全站上最好**（4.63%/32.4%）；**站上 5/10 但跌破 20 最差**（3.54%/23.8%）。
3. **"刚站上"（0~2%）反而最弱**；"强势远离均线"（>5%）明显更强。判断时看"偏离幅度"，不要只看二元条件。
4. 多头排列对"冲高幅度"没有优势，反而非多头（超跌反弹）更高——目标不同，结论不同。
5. 模型里 `close_ma5/10/20/30/60`、`ma5_gt_ma10` 等均线特征本来就在 70 个特征中，不需要额外加；
   它们对"最高价预测"是有效特征（MA5 相关系数 0.26），但对"收盘方向"帮助仍很小（0.05 左右）。

> 实战含义：**优先"站上 MA20 + 远离 MA5（2% 以上）"的信号；"刚站上 MA5/MA10、还没站上 MA20"的最鸡肋。**

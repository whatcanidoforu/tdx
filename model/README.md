# tdx-model：用通达信指标预测「次日收盘价 / 次日最高价」

这个目录是 `tdx-model` 分支新增的模型部分：把 `dsh-tdx` 前端已经实现的
**HJ 指标 + MACD + 日线 OHLCV** 作为特征，训练 LightGBM 模型，
预测每只 A 股**下一个交易日的收盘价和最高价**。

> 分支：`tdx-model`（从 `web` 仓库 `main` 切出）
> 代码位置：`web/model/`
> 数据：`D:\MyTools\new_tdx_day`（本地通达信日线，12,218 个文件）

---

## 1. 结论速览

回测区间：**2025-01-01 ~ 2026-10-21**（413 个交易日，测试集完全不参与训练）

| 任务 | IC 均值 | ICIR | 正 IC 占比 | R² | 方向命中率 |
|---|---|---|---|---|---|
| 预测**次日收盘收益** | **0.0742** | 0.61 | 74.3% | 0.011 | 54.2% |
| 预测**次日最高收益** | **0.2889** | 1.93 | 96.9% | 0.116 | 87.6% |

- 次日收盘：预测最高的 50 只股票，次日平均收益 **+2.08%**（全市场均值 +0.02%）
- 次日最高：预测最高的 50 只，次日平均最高涨幅 **+6.80%**（全市场 +2.09%）
- 分年度：收盘 IC 2025=0.087 / 2026=0.058；最高 IC 2025=0.286 / 2026=0.293

**但要看清这个结果的性质：**

1. 模型 Top50 里 **91.9% 是「当日涨停」的股票**——模型主要学的是 A 股著名的
   **「涨停次日溢价 / 连板延续」**效应。简单规则（按当日涨幅选 Top50）次日只有 +0.96%，
   模型挑出 +2.08%，说明模型在涨停股内部做了进一步筛选，但本质上仍是涨停博弈。
2. 剔除当日涨停样本后，模型对普通股票的 IC 仍有 **0.0709**，说明 HJ/MACD/量价特征
   对次日收益有独立于涨停的信号。
3. 「次日最高收益」的 IC 高达 0.29，**主要来自波动率可预测性**（高波动股票次日最高价
   天然更高），不能把它当成方向判断；方向信号看「次日收盘收益」的 IC 0.074。

## 3. 特征（57 个）

全部只用「当天及以前」的数据，不使用未来信息。

| 类别 | 特征 |
|---|---|
| HJ 指标（对齐 `web/src/formulas/hj.js`） | `hj10`、`hj11`、`hj10-hj11`、`hj5`（买入信号）、`hj_accel`（加速值）、`hj_accel_chg`、加速方向 |
| MACD(12,26,9) | `macd_dif`、`macd_dea`、`macd_hist`、`dif-dea`、`hist`/`dif` 变化、金叉、`dif>dea` |
| 均线 | `close_ma5/10/20/60`（相对收盘）、`ma5/ma20`、`ma20` 斜率 |
| 动量 | 1/3/5/10/20/60 日收益 |
| 震荡指标 | `rsi14`、`kdj` K/D/J、`boll` 位置/宽度、`atr14` |
| 价格行为 | 振幅、实体、上下影线、跳空、收盘位置、20/60 日区间位置、距 20 日高低点 |
| 量能 | 量比 5/20、额比 5、对数成交额、20/60 日波动率 |
| 日历 | 月份 sin/cos、星期 |
| 市场环境 | 上证指数 1/5/20 日收益、指数 20 日波动、全市场上涨家数占比、截面收益均值/标准差 |

> 特征重要性上，**次日收盘**主要靠 `ret1`、`amplitude`、`vol_ratio20`、`gap`、`atr14_pct`、
> 成交额等；**次日最高**主要靠 `ret1`、`atr14_pct`、`amplitude`、`vol20`、`dist_low20`。
> 市场环境特征（指数/宽度）在 gain 里排名高，但它们对“同一天所有股票”取值相同，
> 只影响时间维度的拟合，不参与横截面排序。

## 4. 标签

对每只股票、每个交易日 t：

```text
y_close_ret = close[t+1] / close[t] - 1      # 次日收盘收益
y_high_ret  = high[t+1]  / close[t] - 1      # 次日最高收益（次日最高价相对今日收盘）
```

预测时换算成价格：

```text
pred_close_px = close[t] * (1 + pred_close_ret)
pred_high_px  = close[t] * (1 + pred_high_ret)
```

## 5. 模型与训练

- 模型：**LightGBM 回归**（两个目标各一个模型）
- 参数：`num_leaves=63`、`learning_rate=0.05`、`min_data_in_leaf=500`、
  `feature_fraction=0.8`、`bagging_fraction=0.8`、`lambda_l2=1`、500 轮 + 50 轮早停
- 训练耗时：**2.7 分钟**（16 线程），最佳轮数：收盘 158 轮 / 最高 364 轮
- 时间切分：训练 `<2023-01-01`，验证 `2023~2024`，测试 `>=2025-01-01`
- 评估：按天计算横截面 Spearman IC、十分位多空、Top50 组合、方向命中率

### 泄漏自检

把标签整体后移一天（用 t 日特征预测 t+2），模型在验证集第 **3 棵树**就早停，
IC ≈ 0；而预测 t+1 的 IC 为 0.074。说明特征里没有混入未来信息，
t+1 的信号是真实的（至少在测试期内）。

## 6. 快速使用

环境：Python 3.11 + `pandas / numpy / lightgbm / scikit-learn / scipy / pyarrow`
（本机使用 conda 环境 `firstmodel`）

```bash
cd D:\MyTools\zlf\dsh-tdx\web\model

# 1) 构建数据集（约 4 分钟；首次会生成 data/panel.parquet，约 3GB）
python build_dataset.py --data-root D:\MyTools\new_tdx_day

# 2) 训练（约 3 分钟）
python train.py --max-rounds 500

# 3) 预测最新交易日（输出到 output/predictions_YYYYMMDD.csv）
python predict.py --top 20
```

输出文件：

```
model/output/
├── lgb_y_close_ret.txt      # 次日收盘模型
├── lgb_y_high_ret.txt       # 次日最高模型
├── metrics.json             # 测试集全部指标（IC/R²/分年/十分位）
├── importance_*.csv         # 特征重要性
├── predictions_20261022.csv # 最新一日全市场预测
└── prediction_summary_*.json
```

`predict.py` 会同时打印三个榜：

1. 预测次日收盘涨幅 TopN（含预测收盘价/最高价）
2. **排除当日涨停后**的 TopN（当天涨停封死买不进，这个榜更接近可操作清单）
3. 预测次日最高涨幅 TopN

## 8. 局限与风险（务必阅读）

1. **幸存者偏差**：TDX 本地数据只有当前仍在列表的股票，退市股缺失，回测收益会被高估。
2. **交易不可行性**：模型 Top50 主要是当日涨停股，实际盘中往往买不进；且未考虑
   手续费、滑点、冲击成本、涨跌停无法成交。
3. **次日最高价不可直接交易**：预测的「最高价」只是一个波动幅度估计，实盘无法保证卖在最高点。
4. **测试期仅 1.8 年、单一行情**：IC 会随市场风格变化，不能保证未来稳定。
5. 这不是投资建议，只是「指标 → 次日价格」的机器学习建模练习，实盘使用前必须做
   更严格的滚动回测和风控。

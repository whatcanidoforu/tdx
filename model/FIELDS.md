# 字段说明（FIELDS.md）

本文档整理 4 日 OHLC 预测模型（`four_day_forecast.py`）的关键字段、单位与含义。
对应数据：`D:\MyTools\new_tdx\vipdoc\{sh,sz,bj}\lday` 通达信日线。

---

## 1. 信号（买入条件）

T 日收盘同时满足以下条件：

| 条件 | 实现 |
|---|---|
| HJ10 上穿 HJ11 | `hj10[t] > hj11[t]` 且 `hj10[t-1] <= hj11[t-1]` |
| K 日递降 | 交叉前连续 K 天 `hj10 < hj11`（默认 K=3，可用 `--streak` 调 1/2/4/5） |
| MACD DIFF 增大 | `dif[t] > dif[t-1]`，`dif = EMA12(close) - EMA26(close)` |

脏数据过滤：`|T 日涨跌幅| > 35%` 或 `T 日振幅 > 50%` 的行删除（830,626 行中仅 56 行）。

满足条件的 T 日收盘价买入。T 日之后第 1~4 个交易日记为 T+1、T+2、T+3、T+4。

---

## 2. 预测输出 CSV 的列

文件：`output_4day/predict_4day_YYYYMMDD.csv`

| 列名 | 单位 | 含义 |
|---|---|---|
| `stock_code` | — | 股票代码（6 位） |
| `market` | — | 市场：`sh` 沪市、`sz` 深市、`bj` 北交所 |
| `signal_date` | YYYYMMDD | **信号日 T（买入日）**，这天收盘满足买入条件 |
| `buy_close` | 元 | T 日收盘价（买入价） |
| `T_ret_pct` | % | T 日（信号日）当天的涨跌幅 |
| `T+1_open`、`T+1_high`、`T+1_low`、`T+1_close` | 元 | 模型预测的 T+1 日开盘/最高/最低/收盘价 |
| `T+2_*`、`T+3_*`、`T+4_*` | 元 | 同上，分别对应第 2/3/4 个交易日 |
| `T+1_high_ret_pct` | % | 预测 T+1 最高价相对买入价的涨幅 |
| `max_high_4d_ret_pct` | % | 预测 T+1~T+4 四天中最高价相对买入价的最大涨幅（排序用） |
| `target_dates` | — | 预测覆盖的 4 个交易日（按周一~周五粗略推算，未考虑节假日） |

> 价格单位都是元；`_ret_pct` 是百分数，例如 10.07 表示 +10.07%。

---

## 3. 模型目标（16 个）

每个目标都是**相对 T 日收盘价的收益率**（训练时用收益，输出时换算成价格）：

```text
h{1..4}_open  = open[T+h]  / close[T] - 1
h{1..4}_high  = high[T+h]  / close[T] - 1
h{1..4}_low   = low[T+h]   / close[T] - 1
h{1..4}_close = close[T+h] / close[T] - 1
```

预测价格 = `close[T] × (1 + 预测收益率)`。

## 4. 输入特征（66 个）

### 4.1 HJ 指标（来自 `web/src/formulas/hj.js`）

| 字段 | 含义 |
|---|---|
| `hj10` | HJ 主振荡线（0~100） |
| `hj11` | HJ 信号线（0~100） |
| `hj10_hj11` | 两线差值 |
| `hj5` | 买入信号（HJ4 上穿 HJ2 且满足条件，0/1） |
| `hj_accel` | 加速值 - 100 |
| `hj_accel_side` | 加速值在 100 上方/下方（+1/-1） |
| `hj_accel_dir` | 加速度变化方向（+1/-1） |

### 4.2 MACD(12,26,9)

| 字段 | 含义 |
|---|---|
| `macd_dif`、`macd_dea`、`macd_hist` | DIFF/DEA/MACD 柱，均除以收盘价 ×100（%） |
| `macd_dif_dea` | DIFF - DEA |
| `macd_hist_chg`、`macd_dif_chg` | 柱/ DIFF 的日变化 |
| `macd_cross_up`、`macd_above` | 金叉（0/1）、DIFF 在 DEA 上方（0/1） |

### 4.3 均线（5/10/20/30/60 日）

| 字段 | 含义 |
|---|---|
| `close_ma5`、`close_ma10`、`close_ma20`、`close_ma30`、`close_ma60` | 收盘价相对各均线的偏离（%） |
| `ma5_ma20` | MA5 相对 MA20 的偏离 |
| `ma20_slope5` | MA20 最近 5 日斜率 |
| `ma5_gt_ma10`、`ma10_gt_ma20`、`ma20_gt_ma30`、`ma30_gt_ma60` | 均线多头排列标志（0/1） |
| `ma_bull_count` | 上述 4 个标志之和（0~4，越大越像多头排列） |

### 4.4 动量 / 震荡 / 价格行为

| 字段 | 含义 |
|---|---|
| `ret1`、`ret3`、`ret5`、`ret10`、`ret20`、`ret60` | 1/3/5/10/20/60 日收益率 |
| `rsi14` | RSI（0~100） |
| `kdj_k`、`kdj_d`、`kdj_j`、`kdj_kd` | KDJ 指标 |
| `boll_pos`、`boll_width` | 收盘价在 BOLL 带中的位置（0~1）、带宽 |
| `atr14_pct` | ATR14 / 收盘价（波动率） |
| `amplitude` | 当日振幅（（最高-最低）/ 昨收） |
| `body` | 实体（（收盘-开盘）/ 昨收） |
| `upper_shadow`、`lower_shadow` | 上/下影线（相对昨收） |
| `gap` | 跳空（开盘 / 昨收 - 1） |
| `close_pos` | 收盘价在当日高低区间的位置（0~1） |
| `pos20`、`pos60` | 收盘价在 20/60 日区间的位置（0~1） |
| `dist_high20`、`dist_low20` | 距 20 日最高/最低的涨跌幅 |
| `month_sin`、`month_cos`、`dow` | 月份 sin/cos、星期（0~4） |

### 4.5 量能（放量/缩量）——第 6 条重点

| 字段 | 含义 |
|---|---|
| `vol_ratio5`、`vol_ratio20`、`vol_ratio60` | 成交量 / 5/20/60 日均量（>1 放量，<1 缩量） |
| `vol_chg1` | 成交量相对昨日变化率 |
| `vol_ma5_ma20` | 5 日均量相对 20 日均量（量能趋势） |
| `amt_ratio5`、`amt_ma5_ma20` | 成交额对应的量比/趋势 |
| `log_amount` | 对数成交额 |
| `vol20`、`vol60` | 20/60 日收益率波动率 |
| `price_vol_corr20` | 近 20 日涨跌幅与成交量变化的相关系数（量价配合） |

> 说明：特征里既有「绝对量比」，也有「量能趋势」，模型可以自己学习放量/缩量与冲高幅度的非线性关系。

### 4.6 影线形态（第 2 条新增）

| 字段 | 含义 |
|---|---|
| `upper_share` | 上影线 / 当日振幅（0~1，越大上影越长） |
| `lower_share` | 下影线 / 当日振幅（0~1） |
| `shadow_ratio` | 上影 / (上影+下影)，0.5=一样长；>0.5 上影主导，<0.5 下影主导 |
| `body_share` | 实体 / 振幅（越接近 1 越像光头光脚/一字板） |

> 判定参考：影线占振幅 ≤10% 为短，10~30% 正常，30~50% 偏长，>50% 很长。
> 详见 README 第 13.6 节。

## 6. 测试集效果（2026 年以后）

| 目标 | MAE（模型） | MAE（直接用 0 预测） | R² | IC |
|---|---|---|---|---|
| T+1 开盘 | 0.90% | 0.90% | 0.07 | 0.13 |
| **T+1 最高** | **1.90%** | 2.55% | **0.12** | **0.31** |
| **T+1 最低** | **1.43%** | 2.29% | **0.12** | **0.35** |
| T+1 收盘 | 2.39% | 2.39% | 0.01 | 0.06 |
| T+2 最高 | 3.18% | 3.54% | 0.06 | 0.18 |
| T+3 最高 | 4.14% | 4.39% | 0.04 | 0.15 |
| T+4 最高 | 4.92% | 5.07% | 0.02 | 0.11 |
| T+4 收盘 | 4.99% | 4.94% | -0.01 | 0.05 |
| **平均（16 个目标）** | **3.29%** | **3.51%** | — | — |

**结论**：
- **最高价、最低价**（波动区间）能预测，T+1 最高价 MAE 从 2.55% 降到 1.90%，IC 0.31；
- **开盘价、收盘价**几乎预测不了（MAE 和「直接用 0 预测」差不多，IC 接近 0）——方向仍然是难题；
- 时间越远（T+3/T+4）误差越大，符合预期。

## 7. 量能分析结论（第 6 条）

按 T 日 `vol_ratio20`（成交量 / 20 日均量）分组，统计后续 3 日最高涨幅：

| 量能分组 | 信号数 | 3 日最高均值 | 4 日最高均值 | 3 日收盘均值 | 冲高≥5% 比例 |
|---|---|---|---|---|---|
| <0.7 缩量 | 144,430 | 3.60% | 4.27% | 0.31% | 22.8% |
| 0.7–1.0 | 216,145 | 3.75% | 4.45% | 0.24% | 25.2% |
| 1.0–1.5 | 258,751 | 4.22% | 5.00% | 0.36% | 29.3% |
| 1.5–2.0 | 112,432 | 4.64% | 5.45% | 0.46% | 33.3% |
| >2.0 放量 | 97,677 | **5.03%** | **5.82%** | 0.32% | **36.3%** |

- `vol_ratio20` 与 3 日最高涨幅的相关系数：**+0.075**
- 消融：加入量能特征后，16 个目标平均 MAE 3.289% → **3.288%**（几乎无变化）

**结论**：放量确实对应更高的「冲高幅度/概率」（3 日最高均值 3.60% → 5.03%，冲高≥5% 概率 22.8% → 36.3%），
但对**收盘方向**帮助很小；量能主要通过波动率影响最高点。模型能利用这类模糊关系，但提升有限，不能过度解读。

## 8. 使用与注意

```powershell
D:\conda\envs\firstmodel\python.exe four_day_forecast.py
```

- 输出：`output_4day/predict_4day_YYYYMMDD.csv`（最新信号日的 4 日 OHLC 预测）
- 全量信号数据：`output_4day/signals4_K3.parquet`（830,626 条，可重新生成）
- 旧 K=0 数据：`output_4day/signals4.parquet`（保留）
- 模型：`output_4day/mlp_4day.pt`
- 指标：`output_4day/metrics_4day.json`

**注意**：
1. 预测的是「价格路径的统计期望」，**不是精确点位**；T+3/T+4 误差很大。
2. 开盘价/收盘价方向基本不可预测，不要把预测收盘价当方向信号。
3. 最高价/最低价预测可用来设止盈/止损参考区间，但实盘未必能成交在极值。
4. 未考虑手续费、滑点、涨停买不进。
5. 数据含退市股，仍有幸存者偏差；不构成投资建议。

## 9. 回测（预测?实际对照）

`backtest_4day.py` 会把每个字段输出成 **`预测价?实际价`** 的格式，例如：

```
20.24?20.45      # T+1 开盘：模型预测 20.24，实际开盘 20.45
21.18?21.01      # T+1 最高：模型预测 21.18，实际最高 21.01
```

覆盖 T+1 ~ T+4 每天的开盘/最高/最低/收盘（16 列），另含 `T_ret_pct`（T 日涨跌幅）、
`pred_max_high_4d_ret_pct`（预测 4 日最高涨幅）。

```powershell
# 单日回测（样本外，2026 年以后）
D:\conda\envs\firstmodel\python.exe backtest_4day.py --date 20260615 --top 10

# 保存明细
D:\conda\envs\firstmodel\python.exe backtest_4day.py --date 20260615 --save bt.csv

# 区间回测（只输出误差汇总）
D:\conda\envs\firstmodel\python.exe backtest_4day.py --start 20260901 --end 20261027
```

注意：模型训练集 `<2025`，2025 是验证集，**2026 年之后才是样本外**；回测 2024 年以前会偏乐观。

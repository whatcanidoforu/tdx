# HJ10 底背离（15 分钟）参数敏感性回测

把 `deepseek-plugin/dsh-tdx/app/hj-pivot-scanner.mjs` 的判定逻辑做成参数网格回测，
回答：**各个参数如何影响 T+1 的平均收益、最大收益、最小收益、胜率**。

## 口径（与扫描器完全一致）

| 项目 | 定义 |
|---|---|
| 信号 | 15 分钟 HJ10 底背离链的最后一个拐点 |
| 买入价 | 该拐点 15 分钟 K 线收盘价 |
| T+1 收益 | (下一个交易日最高价 − 买入价) / 买入价 |
| 数据 | `D:\MyTools\new_tdx\vipdoc\{sh,sz,bj}\fzline\*.lc5`（2026-07-16 ~ 2026-11-06，76 个交易日） |
| 范围 | 2026-06-01 ~ 2026-11-06 内触发信号 |

> 单只股票在范围内可能触发多次，本回测**每次链成链都算一笔**（扫描器只取最长的一条链）。

## 脚本

| 文件 | 作用 |
|---|---|
| `backtest-hj-pivot.mjs` | 全市场信号明细 + 单参数粗筛（输出 `signals_all.csv`、`param_sensitivity.csv`） |
| `param-sweep.mjs` | **一次读盘、全参数网格**（输出 `param_sweep.csv`，约 70 秒扫完全市场） |
| `output/signals_all.csv` | 基准参数下单笔明细（3,338 条信号） |
| `output/param_sweep.csv` | 单参数 + 2,943 种组合的统计 |

```bash
# 基准明细
node backtest-hj-pivot.mjs --start=20260601 --end=20261106

# 全参数网格（推荐）
node param-sweep.mjs
```

## 基准结果（默认参数 threshold=25, minDown=2, reboundCap=25, 有DIF, gap=3, rise=0）

| 周期 | 样本 | 平均 | 最大 | 最小 | 胜率 |
|---|---|---|---|---|---|
| T+0 | 3,229 | +2.15% | +26.79% | -1.11% | 92.3% |
| **T+1** | **3,338** | **+3.00%** | **+64.79%** | **-25.81%** | **78.3%** |

## 单参数影响（T+1，全市场，2026-06-01 ~ 2026-11-06）

### 1. threshold（低点 HJ10 阈值）——影响最大

| 取值 | 样本 | 平均 | 最大 | 最小 | 胜率 |
|---|---|---|---|---|---|
| **10** | 37,553 | **+4.46%** | +31.70% | -50.65% | **87.5%** |
| 15 | 308,320 | +3.82% | +46.22% | -50.65% | 85.3% |
| 20 | 836,935 | +3.27% | +64.79% | -50.65% | 82.1% |
| 25（默认） | 1,320,052 | +2.91% | +64.79% | -50.65% | 80.8% |
| 30 | 1,615,049 | +2.75% | +64.79% | -50.65% | 80.2% |

**阈值越小越好**：HJ10<10 时平均 +4.46%、胜率 87.5%，比默认 <25 高 1.5 个百分点。

### 2. reboundCap（两点之间反弹上限）——第二重要

| 取值 | 样本 | 平均 | 胜率 |
|---|---|---|---|
| **15** | 107,794 | **+4.37%** | **86.9%** |
| 20 | 359,992 | +3.62% | 82.8% |
| 25（默认） | 732,191 | +3.17% | 80.6% |
| 30 | 1,138,426 | +2.93% | 80.7% |
| 40 | 1,779,506 | +2.77% | 81.2% |

**要求两低点之间几乎没反弹过越好**（reboundCap 越小越强）。

### 3. useDif（DIF 条件）——**关掉反而更好**

| 取值 | 样本 | 平均 | 胜率 |
|---|---|---|---|
| **off（关）** | 2,969,152 | **+3.12%** | **81.8%** |
| on（开，默认） | 1,148,757 | +2.71% | 79.8% |

DIF 条件没有提升效果，反而拉低平均和胜率。

### 4. minHj10Rise（相邻低点 HJ10 最小抬升）——**越小越好**

| 取值 | 样本 | 平均 | 胜率 |

| 10 | 126,544 | +2.27% | 79.3% |

要求 HJ10 抬得更多会筛掉好信号。

### 5. minDownBars（左侧连跌根数）——影响很小

| 取值 | 样本 | 平均 | 胜率 |

## 最优组合

**样本 ≥1000 的最佳组合（T+1 平均 +4.80%、胜率 89.0%）：**

```
threshold 15~30 都行（实际由 reboundCap 主导）
minDownBars = 2
reboundCap = 15      ← 关键
useDif = 关（--no-dif）
minGap = 3
minHj10Rise = 0
```

**样本 200~1000 的更激进组合（T+1 平均 +5.72%、胜率 88.9%）：**

```
threshold = 10       ← 更极端的超跌
minDownBars = 1
reboundCap = 15
useDif = 关
minGap = 3
```

## 推荐参数

| 场景 | 参数 | 预期 |
|---|---|---|
| **稳健** | `--rebound-cap=15 --no-dif` | ~1,900 笔，平均 +4.80%，胜率 89% |
| **激进** | `--threshold=10 --min-down=1 --rebound-cap=15 --no-dif` | ~600 笔，平均 +5.72%，胜率 89% |
| 默认 | `--threshold=25 --rebound-cap=25`（带 DIF） | 3,338 笔，平均 +3.00%，胜率 78% |

```bat
:: 稳健版
node hj-pivot-scanner.mjs --rebound-cap=15 --no-dif

:: 激进版
node hj-pivot-scanner.mjs --threshold=10 --min-down=1 --rebound-cap=15 --no-dif
```

## 重要提醒

1. **参数扫描有数据窥探风险**：2,943 组组合里挑最好的，会过拟合。
   上面"稳健版"用了 1,896 笔样本、且由两个独立参数（reboundCap、useDif）共同指向，
   相对可信；"激进版"只有 600 笔，需要更长时间验证。
2. **T+1 最大收益 +64.79% 是极端值**（多为连板/次新），平均 +3% 才是常态。
3. **最小收益 -50.65%** 出现在长周期上，说明这套信号**必须止损**。
4. 本回测只覆盖 76 个交易日（.lc5 数据范围）。
